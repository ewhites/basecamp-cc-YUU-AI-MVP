# Module 02 — Comparing AI Models

> SOURCE OF TRUTH. The module chatbot may only teach what is written here.
> Citation keys: M02-S1 …

## M02-S1 — Why compare models at all

Different models are better at different jobs. The point of this module is not to
crown a winner. It is to teach students a repeatable comparison method they can run
again in two years on models that do not exist yet.

## M02-S2 — The three-axis comparison

Year Up United compares models on exactly three axes, in this order:

1. **Fit** — does it do the job at all?
2. **Trust** — can you check its work, and does it tell you when it is unsure?
3. **Cost** — money, time, and access, together.

Students must score all three. A model that wins on Fit and loses on Trust does not
win the comparison. **Trust is the tiebreaker**, not Cost.

## M02-S3 — The same-prompt rule

A comparison is only valid if every model gets the **byte-identical prompt**. Students
may not reword a prompt to "suit" a model. If a prompt must change, the comparison
restarts for all models.

## M02-S4 — Minimum sample size

Three runs per model, per prompt. One run is an anecdote. The module requires three
and asks students to record all three outputs, not just the best one.

## M02-S5 — What this course has access to

This course provides students with Claude. Other models are discussed in the
curriculum but are not provisioned to students in this cycle. Students compare using
the outputs supplied in the lab materials for non-Claude models; they do not create
their own accounts on other services.

Students must not create personal accounts on outside AI services to complete
coursework. This is a security requirement, not a preference.

## M02-S6 — Recording a comparison

The comparison table students submit has fixed columns:

| Model | Prompt id | Run 1 | Run 2 | Run 3 | Fit /5 | Trust /5 | Cost /5 | Verdict |

A submission missing the three run columns is returned unscored.

## M02-S7 — The stop conditions still apply

The three stop conditions from M01-S6 apply to model comparison too. In particular,
students may not paste personal data into any model to test it, including their own.
