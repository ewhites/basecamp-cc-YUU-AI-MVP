# YUU AI Lab: MVP shell

This is a static login page and dashboard for the Year Up United AI Curriculum Simulator. It has no build step and no dependencies.

## Run
Open `index.html` in a browser, or serve the folder with `npx serve .`.

## Activities
- **Bot Builder** (`bot-builder.html`): a 10-lesson guide to building a Gmail-sorting agent with Claude, covering skills, MCP connectors and scheduled tasks. It includes a progress tracker, a Category Designer that generates `SKILL.md`, knowledge checks, diagrams and no-code alternatives. Progress is saved per user in the browser (localStorage).
- Prompting Lab, Model Comparison and Course Journey are still placeholders.
